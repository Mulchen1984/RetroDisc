RETRODISC — PORTABLE WINDOWS APP BAUEN
========================================

VERALTET — NICHT MEHR BEFOLGEN.
Diese Anleitung beschreibt den alten retrodisc_onefile.spec-Weg, nennt das
inzwischen ersetzte openai-whisper (produktiv ist faster-whisper mit
gebündeltem Basismodell) und gibt eine Größe von 120-150 MB an. Die
produktive EXE ist rund 480 MB groß (gemessen: 502901640 Bytes) und bündelt
FFmpeg, FFprobe, yt-dlp, die DVD-Werkzeuge und das Whisper-Modell.
Gültiger Bauweg: python build.py --clean (siehe README.md und CLAUDE.md).
Die Datei bleibt nur als historischer Beleg erhalten.

Dieses Paket enthält den kompletten Quellcode für RetroDisc.
Deine Aufgabe: Daraus eine portable RetroDisc.exe für Windows bauen.

ZIEL
----
Eine einzige Datei: RetroDisc.exe (~120-150 MB)
- Keine Installation nötig
- Kein Internet beim Start nötig  
- Einfach doppelklicken und läuft

SCHRITTE
--------

1. Python 3.11+ installieren (falls nicht vorhanden)
   https://www.python.org/downloads/windows/
   WICHTIG: "Add Python to PATH" ankreuzen!

2. Dependencies installieren:
   pip install pyinstaller pywebview pydantic structlog rich click httpx yt-dlp sounddevice soundfile certifi openai-whisper scenedetect librosa

3. FFmpeg für Windows laden (einmalig ~85 MB):
   python prepare_vendor.py

4. EXE bauen:
   pyinstaller retrodisc_onefile.spec --clean --noconfirm

5. Fertig:
   dist\RetroDisc.exe

FALLS PROBLEME
--------------
- Antivirus blockiert EXE → False Positive bei PyInstaller, Ausnahme eintragen
- SmartScreen Warnung → "Weitere Informationen" → "Trotzdem ausführen"  
- Erster Start langsam → Normal, PyInstaller entpackt einmalig nach %TEMP%
- FFmpeg-Download schlägt fehl → Manuell von github.com/BtbN/FFmpeg-Builds
  ffmpeg.exe + ffprobe.exe → vendor\ Ordner legen
